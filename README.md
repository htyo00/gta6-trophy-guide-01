An offline guide and tracker for all **55 Grand Theft Auto VI trophies** on PlayStation 5 (1 platinum, 2 gold, 6 silver, 46 bronze) — built for the [gta6-trophy-guide-01 competition on make.fun](https://make.fun/c/gta6-trophy-guide-01).

## What it does

- **Checklist tracker** — tick trophies off as you earn them; progress saves in the browser (localStorage) and can be exported to a file and imported back.
- **Filters** — by kind (story, missable, collectibles, activities, online), by grade, by text search, and by earned / not earned / missable only.
- **Spoiler setting** — hides the names and descriptions of story trophies until they are earned.
- **Roadmap to platinum** — six stages built from the official descriptions, each with its own progress count.
- **Missables page** — the 14 trophies that need one clean attempt, flagged from the official descriptions.
- **Next up planner** — the five most useful trophies to chase next: missables first, then story, then the nearest counts.
- **Guides with sources** — every trophy has a guide in our own words, and the sources (Exophase trophy list, PSNProfiles trophy list) are linked beside each guide. Steps that go beyond the official description are marked honestly when they have not been checked in the game.
- **Progress counters** — PSN targets from the official list (250 Stunts, 42 Shooting Range challenges, 100 WAiNK locations, and more) with a counter you can fill in per trophy.
- **Notes per trophy** — jot down where you found something or what worked.
- **Two themes** — paper (light) and night (dark).

## Run it

Serve `app/` with any static server and open `index.html`. It works with the network off — every file it loads lives under `app/`.

## Honesty note

This guide is built only from the official trophy names, descriptions and grades as PlayStation publishes them, plus the counts on the PSN trophy list. We did not play the game to verify locations or mission steps, and the guide says so wherever that matters instead of inventing them.
